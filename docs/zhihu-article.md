# 我用 AI 搭了一个自动写爆款文章的系统，每天自动产出公众号内容

> 从热点扫描到文章生成，全流程自动化。开源免费， anyone can use.

---

## 背景

做公众号最头疼的是什么？

**选题。**

每天睁眼第一件事就是：今天写什么？看热点、找角度、构思、写稿……一套流程下来，半天就没了。

我花了一个周末，用 AI 搭了一套**热点自动采集 + 文章生成**系统，现在每天自动产出公众号文章。

不是那种"AI 生成→复制粘贴"的半成品，而是完整的流水线：

1. **自动扫描**知乎/微博/抖音当日热榜
2. **深度采集**热点背后的详情和素材
3. **AI 生成**公众号文章、小红书笔记、抖音口播脚本
4. **一键输出**Markdown/JSON 格式，直接可用

全程不需要人工干预，早上起来就能看到 3 篇不同平台的内容。

## 技术架构

整体思路很简单，就 4 步：

```
TrendRadar 热榜数据库
        ↓
   Crawl4AI 深度采集
        ↓
  Qwen / GPT-4 LLM 生成
        ↓
    Markdown / JSON 输出
```

核心代码不到 300 行，用 Python 写的。不需要 GPU，不需要本地部署模型，调 API 就行。

### 关键设计

**1. 零硬编码密钥**

所有 API Key 存在本地 config.yaml，代码里只有占位符。提交 GitHub 前自动扫描，确保不会泄露。

**2. 降级机制**

- TrendRadar 数据不可用 → 自动切换到 MCP 获取
- Crawl4AI 采集失败 → 用热点标题作为基础素材
- LLM API 超时 → 回退到模板生成

保证系统不会因单点故障而崩溃。

**3. 多平台适配**

同一热点，生成 3 种不同风格的内容：
- 公众号：情感故事，1500-2000字
- 小红书：闺蜜聊天风格，300-500字
- 抖音：45秒口播脚本

## 怎么跑起来

```bash
# 1. 克隆项目
git clone https://github.com/witplay/social-content-gen.git
cd social-content-gen

# 2. 安装依赖
pip install -r requirements.txt

# 3. 配置 API
cp config.example.yaml config.yaml
# 编辑 config.yaml，填入 LLM API Key

# 4. 运行
python3 main.py
```

output/ 目录下会生成：
- `article_YYYYMMDD_HHMMSS.md` — 公众号文章
- `content_YYYYMMDD_HHMMSS.json` — 三平台完整内容

## 变现思路

这个项目不只是个玩具，有几个变现路径：

**1. 公众号流量主**
每天自动产出 1-3 篇文章，持续更新 → 开通流量主赚广告费

**2. 多平台矩阵**
同一内容分发到公众号 + 小红书 + 抖音 → 多平台流量

**3. 卖服务**
帮自媒体人搭这套系统，收部署费 + 维护费

**4. 开源引流**
GitHub 开源 → 知乎/小红书写教程 → 导流到付费版（高级功能：自动发布、多账号管理、数据分析）
