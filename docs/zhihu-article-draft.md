## 正文

做自媒体这两年，我最痛苦的就是每天找热点+写内容。

早上打开知乎看热榜，再刷微博、抖音、小红书，一圈下来1小时没了。然后开始写公众号文章，写完再改编成小红书笔记、抖音脚本，又2小时。

**每天光内容创作就要3-4小时，还没算排版发布的时间。**

作为一个人运营的自媒体账号，时间就是钱。所以我花了3天时间，用Python写了个**「自媒体热点内容生成器」**。

### 它能做什么？

简单说就是：**自动追踪全网热点 → 一键生成多平台适配内容**

具体流程：

1. **自动扫描11个平台热榜**
   - 知乎、微博、抖音、B站、头条、澎湃、财联社...
   - 每小时更新一次，不错过任何热点

2. **AI生成多平台内容**
   - 公众号文章：800-1200字，专业风格
   - 小红书笔记：300-500字，活泼emoji风
   - 抖音脚本：60秒口播，口语化

3. **一键输出**
   - JSON格式，方便后续处理
   - 也可以直接导出Markdown

### 实际效果

以今天的热榜第一「黄金大跌」为例：

**公众号文章输出：**
```
标题：黄金大跌，底层逻辑崩了吗？3个信号告诉你真相

最近黄金价格突然大跌，全网都在讨论。作为关注财经的自媒体人，
我认为这个信号值得每个人警惕...

（800字正文，包含数据分析、个人观点、互动引导）
```

**小红书笔记输出：**
```
🔥黄金大跌怎么回事？3分钟看懂背后的逻辑！

姐妹们！最近黄金价格跌得厉害，到底怎么回事？
今天给你说明白👇

✨ 核心要点：
1️⃣ 为什么突然大跌？
2️⃣ 对你有什么影响？
3️⃣ 现在该买还是该卖？
```

**抖音脚本输出：**
```
开场（3秒）：
"黄金大跌！你的首饰还值钱吗？"

正文（30秒）：
"简单说3点：为什么跌、影响谁、怎么办..."

结尾（5秒）：
"关注我，每天3分钟看懂热点"
```
