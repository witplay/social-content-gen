## Title
Show HN: Social Content Gen – Auto-generate social media content from trending topics

## URL
https://github.com/witplay/social-content-gen

## Comment (optional, for HN discussion)
I built this because I was spending 3-4 hours daily scanning trending topics across platforms and writing adapted content for WeChat, Xiaohongshu, and Douyin.

It scans 11 Chinese platforms' trending lists, then uses an LLM to generate platform-specific content:
- WeChat articles (800-1200 words, professional tone)
- Xiaohongshu posts (300-500 words, emoji-rich, casual)
- Douyin scripts (60-second spoken format)

Open source (MIT), supports OpenAI / Qwen / local models.

Would love feedback from the HN community. The code is Python, relatively straightforward to extend for other platforms.
