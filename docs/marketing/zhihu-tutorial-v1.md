# AI自动帮你写内容？我开源了一个热点内容生成器，自媒体人效率翻10倍

> 本文为工具使用教程，附 GitHub 开源链接

## 痛点：自媒体人每天花2-3小时做这些

1. **找热点**：刷微博、知乎、抖音、小红书...逐个平台看
2. **想角度**：这个热点怎么切入？写什么能火？
3. **写内容**：公众号要长文，小红书要emoji+短句，抖音要脚本
4. **改格式**：同一个主题，不同平台要不同的风格

每天光这些就耗掉2-3小时。如果一天发3个平台，就是6-9小时。

## 解决方案：自动化热点→内容生成→多平台适配

我做了一个开源工具，核心流程：

```
自动扫描11个平台热榜 → AI 根据热点生成内容 → 一键输出多平台格式
```

### 实际效果

以今天的热点为例，工具自动扫描到以下TOP热点：

```
 1. [微博] #高考作文题#
 2. [知乎] AI 工具正在改变哪些行业？
 3. [抖音] 夏天必看的10部电影
 4. [B站] 2026年最值得买的数码产品
 5. [小红书] 打工人周末独处指南
```

然后自动生成3个平台的内容：

**公众号文章片段：**
> 2026年高考作文题再次引发全网热议。今年作文题聚焦"科技与人文的平衡"...（约800字完整文章）

**小红书笔记：**
> 🔥今年高考作文题太绝了！
> 
> 看完我只想说：这届考生真的太难了😭
> 
> 题目要求谈谈"科技与人文"...（含emoji，分段短小）

**抖音脚本：**
> （开场3秒）"今年高考作文题，网友看完直接沉默了..."
> （正文）"你知道吗，这道题背后其实藏着一个巨大趋势..."（口语化，1分钟脚本）

## 怎么用？

### 安装

```bash
git clone https://github.com/witplay/social-content-gen.git
cd social-content-gen
pip install -r requirements.txt
```

### 配置（可选，支持本地模型）

```yaml
# config.yaml
llm:
  provider: openai_compatible
  api_key: "your-api-key"  # 也可以用本地模型，无需API
  base_url: "https://api.example.com/v1"
  model: "deepseek-chat"
```

### 使用

```bash
# 一键生成：热点扫描 + 内容生成
python main.py

# 指定平台
python main.py --platforms 公众号 小红书 抖音

# 指定热点关键词
python main.py --keyword "AI"
```

### 输出

生成结果保存在 `output/` 目录，JSON格式，可以直接复制使用：

```json
{
  "generated_at": "2026-06-04T18:00:00",
  "topics": ["高考作文题", "AI工具改变行业"],
  "content": {
    "wechat": "...",
    "xiaohongshu": "...",
    "douyin": "..."
  }
}
```

## 适合谁？

- ✅ 自媒体运营：每天要发多个平台
- ✅ 内容创作者：需要持续输出但时间不够
- ✅ 营销人员：需要快速响应热点
- ✅ 副业赚钱：想做自媒体但不会写
