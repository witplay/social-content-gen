# V2EX 推广帖 — social-content-gen

## 标题
分享一个我写的开源自媒体工具：自动追热点 + 多平台内容生成

## 正文
最近在做一个自媒体号，每天找热点、写文章、适配不同平台太费时间了。

于是花几天写了个 Python 工具，**自动扫描 11 个平台热榜，一键生成公众号/小红书/抖音的适配内容**。

### 功能
- 自动追踪知乎/微博/抖音/B站/头条等 11 个平台热榜
- 一个热点自动生成 3 种格式：公众号长文、小红书笔记、抖音脚本
- 支持 OpenAI / 千问 / 本地模型
- 完全开源，MIT 协议

### 实测数据
| 任务 | 人工 | 工具 |
|------|------|------|
| 扫描11平台热点 | 45分钟 | 30秒 |
| 写公众号文章 | 60分钟 | 2分钟 |
| 多平台适配 | 90分钟 | 1分钟 |

### 效果示例
输入热点：「2026高考1290万人报名」

输出：
- 公众号：《那个在考场外等了3小时的母亲，让1290万人的高考有了温度》（2300字）
- 小红书：「1290万人今天高考💯考场外的一幕让我破防了」（450字）
- 抖音：60秒口播脚本

### 安装
```bash
git clone https://github.com/witplay/social-content-gen.git
cd social-content-gen
pip install -r requirements.txt
python main.py
```
